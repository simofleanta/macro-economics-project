BVB Stocks vs. Romanian Inflation

A small macroeconomics project comparing nominal stock returns on the Bucharest Stock Exchange (BVB) against Romania's inflation-adjusted ("real") returns, and testing whether inflation statistically predicts annual stock performance.

Chart 1 — Nominal vs. Real Returns

Cumulative and monthly nominal vs. inflation-adjusted returns for 5 BVB stocks, 2021–2025.

Chart 2 — Inflation-Return Regression

Scatter plots and regression lines, plus a sensitivity chart showing how statistical significance depends on the time horizon used.
See the repository for the data-collection and analysis scripts, and README.md for methodology and data sources.
